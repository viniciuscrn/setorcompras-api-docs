---
title: API SETOR COMPRAS
---

API REST do setor de compras de prefeituras e órgãos públicos. Cada instituição tem banco próprio e é acessada pelo
slug na URL: `/api/{ente}/...` (ex.: `/api/agua-branca/login`).
